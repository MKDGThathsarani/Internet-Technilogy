📖 Week 01 & 02 — Topic Summary

🌍 What is the Internet?

The Internet is a vast, global system of interconnected computer networks that communicate through standardized protocols. It connects billions of devices across the world, enabling seamless information sharing, real-time communication, and access to countless digital services. In essence, the Internet functions as a "network of networks" spanning the entire planet.

⚙️ How the Internet Works

Client-Server Model

Clients (devices) request services from servers (powerful computers that store data and applications). The server responds with the requested information.

HTTP (HyperText Transfer Protocol)

The protocol used to transfer web pages from servers to browsers. It defines how messages are formatted and transmitted.

DNS (Domain Name System)

Translates human-friendly domain names (e.g., google.com) into IP addresses that computers use to identify each other.

🛠️ Main Services on the Internet

  • 🌐 World Wide Web (Websites & Web Apps)
  • 📧 Email (Gmail, Outlook, etc.)
  • ☁️ Cloud Computing (Google Drive, AWS)
  • 📱 Social Media (Facebook, Instagram, Twitter)
  • 💰 Online Banking & E-commerce
  • 🎥 Streaming (YouTube, Netflix, Spotify)

📱 How the Internet is Used in Daily Life

  • 📚 Education — Online courses, research, e-libraries
  • 🏥 Healthcare — Telemedicine, health records
  • 💼 Business — Remote work, video conferencing
  • 🎮 Entertainment — Gaming, music, movies
  • 🏠 Smart Homes — IoT devices, voice assistants

🌐 Role of Web Browsers

Web browsers (Chrome, Firefox, Safari, Edge) are software applications that allow users to access and view websites. They interpret HTML, CSS, and JavaScript to render web pages, handle user interactions, and manage cookies, cache, and security.

🔍 What is DNS & Why is it Important?

DNS (Domain Name System) is like the "phonebook of the internet." It translates domain names (e.g., www.example.com) into IP addresses (e.g., 192.168.1.1) so that browsers can load resources. Without DNS, users would have to remember complex numeric IP addresses for every website.

📄 Document Structure Tags

<!DOCTYPE html>
Purpose: Declares the document type and HTML version.
When to use: Always the first line in an HTML document.
<!DOCTYPE html>
<html>
Purpose: Root element of an HTML page.
When to use: Wraps all content on the page.
<html lang="en"> ... </html>
<head>
Purpose: Contains meta-information about the document.
When to use: Place inside <html> before <body>.
<head><title>My Page</title></head>
<title>
Purpose: Sets the title shown in the browser tab.
When to use: Inside <head>.
<title>My Website</title>
<meta>
Purpose: Provides metadata like charset, viewport, description.
When to use: Inside <head>.
<meta charset="UTF-8">
<link>
Purpose: Links external resources like CSS stylesheets.
When to use: Inside <head>.
<link rel="stylesheet" href="style.css">
<style>
Purpose: Embeds internal CSS styles.
When to use: Inside <head> or inside <body>.
<style> body { color: red; } </style>
<body>
Purpose: Contains all visible page content.
When to use: After </head>.
<body> <h1>Hello</h1> </body>

🧩 Semantic HTML5 Tags

<header>
Purpose: Defines introductory content or navigation.
When to use: At the top of a page or section.
<header><h1>My Site</h1></header>
<main>
Purpose: Represents the dominant content of the page.
When to use: Once per page, wrap main content.
<main> ... </main>
<section>
Purpose: Groups related content with a theme.
When to use: For chapters, tabs, or thematic groups.
<section><h2>About</h2><p>...</p></section>
<article>
Purpose: Represents independent, self-contained content.
When to use: Blog posts, news articles, forum posts.
<article><h3>Blog Post</h3><p>...</p></article>
<footer>
Purpose: Defines footer for a page or section.
When to use: At the bottom of a page or section.
<footer>&copy; 2026</footer>
<nav>
Purpose: Defines navigation links.
When to use: For menus or navigation bars.
<nav><a href="#">Home</a></nav>
<aside>
Purpose: Represents content indirectly related to main content.
When to use: Sidebars, pull quotes, advertisements.
<aside><p>Advertisement</p></aside>

✍️ Text Formatting Tags

<h1> to <h6>
Purpose: Headings from largest (h1) to smallest (h6).
When to use: For titles and subheadings.
<h1>Main Title</h1> <h2>Subtitle</h2>
<p>
Purpose: Defines a paragraph.
When to use: For blocks of text.
<p>This is a paragraph.</p>
<br>
Purpose: Inserts a line break.
When to use: For breaking lines without starting a new paragraph.
Line 1<br>Line 2
<hr>
Purpose: Creates a horizontal rule (thematic break).
When to use: To separate content sections.
<hr>
<strong>
Purpose: Indicates strong importance (bold).
When to use: For important text.
<strong>Important</strong>
<b>
Purpose: Bold text (presentational).
When to use: For styling, not semantic importance.
<b>Bold text</b>
<em>
Purpose: Emphasized text (italic).
When to use: To add emphasis.
<em>Emphasized</em>
<i>
Purpose: Italic text (presentational).
When to use: For styling, technical terms, or thoughts.
<i>Italic</i>
<u>
Purpose: Underlines text.
When to use: For underlined text (use sparingly).
<u>Underlined</u>
<s>
Purpose: Strikethrough text.
When to use: For deleted or no-longer-accurate text.
<s>$100</s> $80
<mark>
Purpose: Highlights text.
When to use: To draw attention.
<mark>Highlighted</mark>
<small>
Purpose: Makes text smaller (side comments).
When to use: For fine print or legal text.
<small>Terms apply</small>
<sub>
Purpose: Subscript text.
When to use: Chemical formulas, math.
H<sub>2</sub>O
<sup>
Purpose: Superscript text.
When to use: Exponents, ordinal indicators.
E=mc<sup>2</sup>
<blockquote>
Purpose: Defines a block quotation.
When to use: For longer quoted text.
<blockquote>To be or not to be.</blockquote>
<q>
Purpose: Inline quotation.
When to use: For short quotes within a sentence.
He said <q>Hello</q>
<cite>
Purpose: Cites a source or reference.
When to use: For titles of works.
<cite>The Great Gatsby</cite>
<code>
Purpose: Displays inline code.
When to use: For code snippets in text.
Use <code>print()</code> to output.
<pre>
Purpose: Preformatted text (preserves spaces and line breaks).
When to use: For code blocks or poetry.
<pre> def hello():\n print("Hi")</pre>
<abbr>
Purpose: Defines an abbreviation or acronym.
When to use: With title attribute for full form.
<abbr title="HyperText Markup Language">HTML</abbr>
<address>
Purpose: Defines contact information.
When to use: For author/contact details.
<address>email@example.com</address>

🔗 Link & Media Tags

<a>
Purpose: Creates a hyperlink.
When to use: For navigation.
<a href="https://example.com">Visit</a>
<img>
Purpose: Embeds an image.
When to use: To display images.
<img src="photo.jpg" alt="Description">
<picture>
Purpose: Provides multiple image sources for responsive design.
When to use: For art direction or different resolutions.
<picture><source srcset="large.jpg" media="(min-width:800px)"><img src="small.jpg"></picture>
<video>
Purpose: Embeds a video.
When to use: To play video files.
<video controls><source src="movie.mp4"></video>
<audio>
Purpose: Embeds audio.
When to use: To play audio files.
<audio controls><source src="song.mp3"></audio>
<source>
Purpose: Specifies media sources for <picture>, <video>, <audio>.
When to use: Inside <picture>, <video>, or <audio>.
<source srcset="image.webp" type="image/webp">
<track>
Purpose: Adds subtitles or captions to video/audio.
When to use: Inside <video> or <audio>.
<track kind="captions" src="captions.vtt">
<iframe>
Purpose: Embeds another HTML page within the current page.
When to use: For embedded videos, maps, or external content.
<iframe src="https://example.com"></iframe>

Purpose: Defines a table.
When to use: For tabular data.
<table>...</table>
<thead>

When to use: Inside <table>.
<thead><tr><th>Name</th></tr></thead>
<tbody>
Purpose: Groups body rows in a table.
When to use: Inside <table>.
<tbody><tr><td>Data</td></tr></tbody>
<tfoot>
Purpose: Groups footer rows in a table.
When to use: Inside <table>.
<tfoot><tr><td>Total</td></tr></tfoot>
<tr>
Purpose: Defines a table row.
When to use: Inside <table>.
<tr><td>Cell</td></tr>
<th>
Purpose: Defines a table header cell.
When to use: Inside <tr> for headings.
<th>Name</th>
<td>
Purpose: Defines a table data cell.

<td>John Doe</td>
<caption>
Purpose: Adds a caption to a table.
When to use: Inside <table>.
<caption>Student List</caption>

📝 Form Tags

<form>
Purpose: Defines an HTML form for user input.
When to use: To collect user data.
<form action="/submit" method="POST">...</form>
<input>
Purpose: Creates an input field.
When to use: Inside <form>.
<input type="text" name="username">
<label>
Purpose: Labels an input field.
When to use: For accessibility.
<label for="name">Name:</label> <input id="name">
<select>
Purpose: Creates a dropdown list.
When to use: For selecting from options.
<select><option>Option 1</option></select>
<option>
Purpose: Defines an option in a dropdown.
When to use: Inside <select>.
<option value="1">One</option>
<optgroup>
Purpose: Groups options in a dropdown.
When to use: Inside <select>.
<optgroup label="Fruits"><option>Apple</option></optgroup>
<textarea>
Purpose: Creates a multi-line text input.
When to use: For longer text like comments.
<textarea rows="4" cols="50"></textarea>
<button>
Purpose: Creates a clickable button.
When to use: For form submission or actions.
<button type="submit">Send</button>
<fieldset>
Purpose: Groups related form elements.
When to use: Inside <form>.
<fieldset><legend>Personal Info</legend>...</fieldset>
<legend>
Purpose: Defines a caption for a <fieldset>.
When to use: Inside <fieldset>.
<legend>Details</legend>
<datalist>
Purpose: Provides autocomplete suggestions for an input.
When to use: With list attribute on <input>.
<input list="browsers"><datalist id="browsers"><option value="Chrome"></datalist>
<output>
Purpose: Displays the result of a calculation.
When to use: After user interaction.
<output name="result">0</output>
