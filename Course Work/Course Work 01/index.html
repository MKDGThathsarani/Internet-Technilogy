Understanding the Internet

What is the Internet?

The Internet is a vast, global system of interconnected computer networks that communicate using standardized protocols. It connects billions of devices worldwide, enabling information sharing, real-time communication, and access to digital services. Simply put, it is a "network of networks" that spans the entire planet.

How the Internet Works

Client-Server Model

Clients (devices) request services from servers (powerful computers). Servers respond with the requested data.

HTTP

HyperText Transfer Protocol is used to transfer web pages from servers to browsers.

DNS

Domain Name System translates domain names (like google.com) into IP addresses.

Main Services on the Internet

  • World Wide Web
  • Email
  • Cloud Computing
  • Social Media
  • Online Banking
  • Streaming (YouTube, Netflix)

Internet in Daily Life

  • Education - Online courses
  • Healthcare - Telemedicine
  • Business - Remote work
  • Entertainment - Gaming
  • Smart Homes - IoT devices

Role of Web Browsers

Web browsers (Chrome, Firefox, Edge, Safari) are software applications that allow users to access websites. They interpret HTML, CSS, and JavaScript to display web pages.

What is DNS and Why is it Important?

DNS is like the "phonebook of the internet." It converts domain names into IP addresses so browsers can load resources. Without DNS, we would have to remember numbers like 192.168.1.1 for every website.

Document Structure

<!DOCTYPE html>
Purpose: Declares the HTML version.
When: First line of every HTML page.
<!DOCTYPE html>
<html>
Purpose: Root element of the page.
When: Wraps all content.
<html lang="en"> ... </html>
<head>
Purpose: Contains meta information.
When: Before body.
<head><title>Page</title></head>
<title>
Purpose: Sets the browser tab title.
When: Inside head.
<title>My Website</title>
<meta>
Purpose: Provides metadata like charset.
When: Inside head.
<meta charset="UTF-8">
<link>
Purpose: Links external CSS files.
When: Inside head.
<link rel="stylesheet" href="style.css">
<style>
Purpose: Embeds internal CSS.
When: Inside head.
<style> body { color: blue; } </style>
<body>
Purpose: Contains visible content.
When: After head.
<body> <h1>Hello</h1> </body>
